# 扫描表格抽取—校对—入库系统（Pointwise Delivery）

四个**独立进程**协作的服务，全部基于 Python 标准库实现（无第三方依赖）：

| 服务 | 端口 | 职责 |
|---|---|---|
| 接收服务 `services/receiver` | 8011 | 扫描件归档、文档版本管理、抽取任务队列、文件与证据存取、陈旧任务拦截 |
| 表格抽取器 `services/extractor` | 8012 | 独立进程，领取任务后做真实像素级表格检测与字形 OCR，回传坐标/置信度/证据 |
| 校对服务 `services/review` | 8013 | 校对网页、逐单元格合并规则、乐观锁并发控制、版本对比、批准后送入库 |
| 入库服务 `services/warehouse` | 8014 | 只接收已批准页面，追加式写入，提供入库记录查询 |

处理流水线是单向的：**扫描件 → 抽取 → 校对 → 校对通过才入库**。

## 真实抽取，而非固定答案

`tools/generate_scans.py` 用自带的 5×7 位图字形逐像素“渲染”出虚构扫描页，
再经过 dropout（断墨）、胡椒噪点、纸张不均匀等扫描劣化，写成灰度 PNG。

`services/extractor/engine.py` 只读取 PNG 像素，真实执行：

1. 二值化；
2. 两阶段网格线检测（高墨率横线 → 在表格高度带内找竖线，容忍断墨间隙）；
3. 网格求交得到单元格，切出单元格内部；
4. 连通域去胡椒噪点、按空白列切分并合并断裂字形；
5. 每个字形在多个尺度上与 5×7 模板做汉明距离匹配，得到字符与置信度；
6. 输出单元格文本、逐字置信度、字符/单元格坐标框（证据）和内容指纹。

内容指纹基于归一化后的识别文本，**与坐标、页码、框外噪点无关**，
因此页码插入导致整张表下移时，相同内容指纹保持不变。

## 新版扫描件的逐单元格合并规则

来源补传新版并重新抽取后，校对服务**既不整页照搬旧校对，也不清空人工修改**。
页面先按整页内容指纹匹配（指纹失败再按文档顺序做结构回退，并用单元格指纹
命中率区分“部分改动页”和“真正插入的新页”），然后逐单元格判定：

| 判定 | 触发条件 | 处理 |
|---|---|---|
| `REUSE` | 单元格内容指纹未变（即使坐标移动） | 复用原校对结论；若有人工修改则保留人工值 |
| `RECHECK` | 内容变化且无人工修改 | 采用新 OCR 值，标记待人工确认 |
| `DRAFT` | 内容变化但该格曾被人工修改 | **保留人工值作为草稿**，要求对照新扫描重新确认，不静默覆盖 |
| `ADDED` | 新版出现、旧版无对应单元格/新插入页 | 采用新 OCR，待校对 |
| `REMOVED` | 旧版单元格在新版消失 | 标记并要求确认 |

## 并发与一致性保障

- **两人同时校对**：每次保存带 `expected_revision` 乐观锁，修订号已变化则返回
  409，后保存者必须基于新修订重试，无法互相覆盖。
- **页码插入导致坐标移动**：匹配基于内容指纹而非坐标，旧校对按内容复用，
  原始坐标与证据随每次抽取完整保留。
- **旧抽取任务晚完成**：抽取结果回传时接收服务校验版本号，属于旧版本一律
  `REJECTED`，永不覆盖新版本数据（`extractor` 的 `/control/hold` 可模拟晚到任务）。

## 运行

```bash
# 1. 生成虚构扫描页（默认写入 sample_input/）
python3 -I tools/generate_scans.py

# 2. 从空数据目录启动四个独立服务
bash tools/start_services.sh          # 停止: bash tools/stop_services.sh

# 3. 端到端演示（走完整 HTTP 流程，含并发冲突与陈旧任务）
PYTHONPATH=$PWD python3 -I tools/demo.py

# 4. 校对网页
open http://127.0.0.1:8013/ui/
```

网页支持：查看原扫描页（带单元格坐标框叠加）、修改单元格、查看置信度与
合并判定、新旧版本逐格对比、查看入库记录与每格来源（OCR/人工）。

## 测试

```bash
PYTHONPATH=$PWD python3 -m unittest discover -s tests -v
```

- `tests/test_merge.py`：逐单元格合并规则（复用/重审/草稿/新增/删除、坐标平移）
- `tests/test_extraction.py`：真实像素抽取、网格/坐标证据、指纹稳定性
- `tests/test_service_flow.py`：四服务端到端流程、乐观锁冲突、晚到旧任务被拒
